## ClawOps로 만드는 것

ClawOps는 한국 전화번호 발급부터 음성 통화와 문자, SIP 연동, 녹음·전사·요약, AI 음성 에이전트까지 제공하는 한국 전화·문자 API 플랫폼입니다.

- 한국 070 전화번호 발급 및 관리
- 전화 발신·수신과 SMS·LMS·MMS
- SIP 트렁크와 기존 PBX 연동
- 통화 녹음·전사·요약
- HMAC 서명된 실시간 Webhook
- Python·Node.js SDK와 REST API
- AI 음성 에이전트

## 빠르게 시작하기

Python:

```bash
pip install clawops
```

Node.js·TypeScript:

```bash
npm install @teamlearners/clawops
```

CLI:

```bash
brew install koreaaitel/tap/clawops
```

설치 후에는 [개발자 문서](https://docs.claw-ops.com)에서 전화번호 발급과 첫 통화 연결 방법을 확인할 수 있습니다.
